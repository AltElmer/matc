MATC Matrix Language

The matrix and expression language embedded in Elmer FEM, written by Juha Ruokolainen.

MATC evaluates expressions, defines functions and manipulates matrices. Inside Elmer it is what makes a solver input file able to compute rather than only declare: a boundary condition can be written as an expression in the coordinates instead of a constant. It also runs on its own as a small interactive calculator.

$ matc
MATC> a = 1:10
MATC> sum(a)
55
MATC> f(x) = x^2 + 1
MATC> f(3)
10
